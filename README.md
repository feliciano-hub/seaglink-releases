# SeagLink para Windows

Instaladores oficiais da Seagmedia.

[Descarregar o instalador](https://github.com/feliciano-hub/seaglink-releases/releases/download/v0.3.0-alpha.24/SeagLink-Setup.exe) · [Todas as releases](https://github.com/feliciano-hub/seaglink-releases/releases)

A versão alpha permite chamadas através do telemóvel associado ao Windows. Confirma a marcação na aplicação. Esta versão ainda não inclui gravação automática.

Este repositório contém a distribuição; o desenvolvimento mantém-se num repositório privado.
